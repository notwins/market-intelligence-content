# Independent content publication
This repository owns new public research and Reuters news. Do not edit or deploy the Hub UI repository to publish content.
Read README.md. Use prepare_research_bundle.py and submit_research.py for complete reports. Private inputs and review receipts stay outside the repository. Never publish a summary as a full report.
Use import_hourly_news.py for reviewed Reuters metadata, preserving baseline history, IDs, times and connected versions. Publish only the changed feed and new archives.
Use latest main and non-force compare-and-swap updates. Wait for this repository's Pages deployment and verify live bytes before claiming success.
Do not change source automation schedules, credentials or older report destinations. The frozen baseline is public provenance, not permission to reissue old articles.
